## 2025-05-15 - Focus Restoration and Keyboard Accessibility in Infinite Grids
**Learning:** In highly visual interfaces with custom infinite-scroll engines and multiple overlays, standard browser focus behavior often breaks. Programmatically managing focus transitions (saving `lastFocusedElement` and using `restoreFocus()`) is essential to prevent keyboard users from getting "lost" in the DOM, especially when overlays are closed. Additionally, infinite/virtualized grid items must be explicitly marked as interactive (`role="button"`, `tabindex="0"`) and handle both `Enter` and `Space` keys to mirror mouse click behavior.
**Action:** Always implement a centralized focus management system (like the `lastFocusedElement` pattern) when using custom overlays. Ensure virtualized grid items are initialized with correct ARIA roles and keyboard listeners during their creation/recycling phase.
