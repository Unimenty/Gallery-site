# Palette's Journal - Kojo Kwarteng Portfolio

## 2025-05-14 - Mandatory Focus Indicators with Custom Cursors
**Learning:** In luxury sites using `cursor: none`, keyboard users are completely lost without high-contrast focus indicators. Standard browser outlines are often suppressed or insufficient against dark editorial backgrounds.
**Action:** Always implement explicit `:focus-visible` styles (e.g., 2px solid white) when the default cursor is hidden to ensure the site remains navigable for all.
